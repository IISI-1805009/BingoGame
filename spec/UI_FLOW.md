# 織城戰線 Woven Rampart — 畫面清單與流程

> 這份文件定義「玩家會看到哪些畫面、畫面如何前進或返回」。戰鬥中的連線、出擊與雙方碰撞屬於戰鬥場景內的狀態／演出，不另開一個可自由跳轉的場景。Godot 實作時，完整畫面使用 `Control` 場景；確認、提示、斷線等則使用覆蓋在目前場景上的 modal／overlay。

## 1. 導航原則

- 所有主流程都能回到主城（Main Hub）；按返回鍵時先回到上一個安全節點，不直接丟失未提交的選擇。
- 進入戰鬥前的選擇先存成 `BattleSetup` 草稿，玩家按「確認／開始」後才送出；取消或斷線可恢復草稿。
- 戰鬥結果先由伺服器／核心規則確認，再播放演出。演出期間不可重複送出動作。
- 需要確認或警告的內容用 overlay，不為每個提示建立新場景，避免手機返回鍵堆出過深的導航歷史。

## 2. 畫面清單

| 畫面／場景 | 類型 | 顯示內容 | 主要互動與離開路徑 |
|---|---|---|---|
| 啟動與存檔恢復 | 全螢幕 | 版本號、本機存檔、登入／連線狀態 | 恢復成功→主城；首次啟動→新手引導；失敗→離線模式或重試 |
| 新手引導 | 全螢幕＋教學 overlay | 城門、選格、跟色、連線、建設的分步說明 | 跳過／完成→主城；第一關可重新觀看 |
| 登入／訪客 | 全螢幕 | 訪客遊玩、帳號登入、帳號綁定、服務條款 | 訪客或登入成功→主城；離線→單機主城 |
| 主城（Main Hub） | 全螢幕 | 城堡入口、玩家等級／經驗、戰功點數、榮譽點數、目前城堡等級 | 進入戰役、PvP、職業訓練所、城堡養成、商店／收藏、設定 |
| 玩家資料／收藏 | 全螢幕 | 已解鎖職業、道具、統計、成就（可延後） | 查看職業／道具詳情；返回主城 |
| 戰役地圖 | 全螢幕 | 章節、46 關、星級、鎖定狀態、首通獎勵 | 選已解鎖關卡→關卡詳情；返回主城 |
| 關卡詳情 | 全螢幕或 bottom sheet | 地圖、主天氣、AI 城堡等級、登場職業、稀有度分布、獎勵、三星條件 | 開始準備、重播教學、返回戰役地圖 |
| 單機戰鬥準備 | 全螢幕 | 本關規則、己方城堡／職業等級、可攜帶道具庫存、預計獎勵 | 選道具／查看職業詳情→確認開始→戰鬥；取消→關卡詳情 |
| PvP 大廳 | 全螢幕 | 快速對戰、對戰規則、已解鎖職業／道具數量、連線品質 | 開始配對→配對中；返回主城 |
| 配對中／找到對手 | 全螢幕＋overlay | 搜尋進度、取消按鈕；找到後顯示對手暱稱、連線檢查、倒數 | 取消→PvP 大廳；雙方確認→地圖選擇 |
| PvP 地圖選擇 | 全螢幕 | 可用地圖、主天氣、地形加成／減益、地圖說明 | 雙方各選／系統決定→共同職業抽選 |
| 共同職業結果 | 全螢幕演出 | 3 個共同職業（建築工固定）、抽選動畫、職業規則摘要 | 確認→個人專屬職業 |
| 個人專屬職業選擇 | 全螢幕 | 自己可選的職業、不能與對手重複、+15% 標籤 | 選擇並確認→道具選擇；逾時依先後手規則處理 |
| PvP 道具選擇 | 全螢幕 | 已解鎖道具、效果、每場 3 格、每格限用 1 次 | 選滿 3 個→擲骰；查看詳情／取消選擇 |
| 先攻擲骰 | 全螢幕演出 | 雙方骰子、先攻方、先攻 +10 戰力值、職業池摘要 | 確認→生成雙方 5×5 盤面→戰鬥 |
| 戰鬥畫面（單機／PvP 共用） | 全螢幕 | 雙方獨立 5×5 盤面；己方全資訊；對方未認領格為灰色未知、已認領格公開角色／稀有度／建設等級；城堡戰力值／DEF、跟色目標、天氣、道具、倒數 | 選格、建設、用道具、投降；連線後在同一場景播放演出 |
| 連線／出擊演出 | 戰鬥內 overlay／狀態 | 城門開啟、部隊衝出、雙方中央碰撞；戰力互相抵消；較多戰力的倖存者攻城；建築工回復獨立顯示 | 純演出，可跳過；結算後回到戰鬥或進入結算 |
| 單機結算 | 全螢幕 | 勝負、星級、戰功點數／經驗、掉落、解鎖提示 | 下一關、再挑戰、返回戰役地圖、回主城 |
| PvP 結算 | 全螢幕 | 勝負、榮譽點數、連線數／出擊統計、對手資訊 | 再來一場、查看收藏、返回 PvP 大廳、回主城 |
| 職業訓練所 | 全螢幕 | 8 個職業等級、被動、攻擊／回復加成、升級費用 | 選職業→職業詳情→升級確認→升級結果；返回主城 |
| 城堡養成 | 全螢幕 | 城堡等級、戰力值、DEF、上限與升級費用 | 升級確認→升級結果；返回主城 |
| 商店／解鎖 | 全螢幕 | 職業庫／道具池分頁、榮譽點數餘額、價格、已解鎖標籤 | 查看詳情→購買確認→購買結果；返回主城 |
| 道具／職業詳情 | modal 或 side sheet | 效果、適用模式、限制、示例 | 關閉回原畫面；從商店可進購買確認 |
| 設定／支援 | 全螢幕 | 音量、語言、通知、帳號綁定、客服／規則說明 | 儲存→返回；登出需確認 overlay |
| 斷線／重連 | overlay | 重新連線進度、目前回合、離線代打提示 | 重連成功→重建目前畫面；逾時→依模式進入單機放棄或 PvP 離場／結算 |
| 通用確認／錯誤 | overlay | 投降、取消配對、購買、升級、網路錯誤、版本不相容 | 確認／取消；錯誤可重試或返回安全節點 |

## 3. 首次啟動與回流流程

```text
啟動
  ├─ 存檔／登入有效 ────────────────┐
  └─ 首次啟動或存檔失效              │
       ↓                             │
    新手引導（可跳過）               │
       ↓                             │
    訪客／登入／離線選擇              │
       └─────────────────────────────┘
                      ↓
                 主城 Main Hub
```

首次啟動直接把玩家帶入第一關教學；完成或跳過後回到主城。回流玩家若有未完成的對戰，先顯示「繼續對局」卡片，再進入戰鬥，不要重新走配對流程。

## 4. 單機戰役流程

```text
主城
  → 戰役地圖
  → 關卡詳情
  → 單機戰鬥準備
       ├─ 查看地圖／職業／獎勵
       ├─ 選擇本次道具（不限 3 格）
       └─ 確認開始
  → 戰鬥
       ├─ 一般回合／連線出擊演出（可多次）
       ├─ 暫停／投降確認
       └─ 斷線時顯示重試或離線繼續
  → 單機結算
       ├─ 勝利：星級、首通獎勵、章節解鎖
       ├─ 失敗：再挑戰或返回關卡詳情
       └─ 下一關／戰役地圖／主城
```

關卡詳情負責「要不要打」的決策；準備畫面負責「這一場怎麼打」的決策，兩者分開可避免玩家反覆查看規則時遺失選擇。

## 5. PvP 對戰流程

```text
主城
  → PvP 大廳
  → 配對中
  → 找到對手／雙方確認
  → 地圖選擇
  → 共同職業結果（建築工＋其餘共同職業）
  → 個人專屬職業選擇（雙方不能重複）
  → 道具選擇（3 個）
  → 先攻擲骰（同點重擲，先攻 +10）
  → 生成雙方獨立 5×5 盤面
  → 戰鬥
  → PvP 結算
       ├─ 再來一場：保留 PvP 大廳偏好，重新配對
       ├─ 查看收藏／商店：處理榮譽點數解鎖
       └─ 主城
```

配對、地圖、職業、道具、擲骰每一步都顯示「目前已確認／尚待確認」；手機返回時只能回到上一個尚未鎖定的步驟。任一步驟逾時由伺服器依規則代選，客戶端只播放結果。

## 6. 戰鬥外的共用狀態與返回規則

### 6.1 建設與成長

`職業訓練所 → 職業詳情 → 升級確認 → 升級結果`，以及 `城堡養成 → 升級確認 → 升級結果` 都採相同的三段式，讓消費戰功點數前一定看得到升級後數值與剩餘資源。升級結果可以用短動畫，不阻塞玩家回到主城。

### 6.2 商店與收藏

商店只處理「解鎖」，收藏處理「查看與比較」。未解鎖項目可看完整規則說明但不顯示不可得的盤面內容；購買成功後立即更新主城與 PvP 開局可選池。若榮譽點數不足，停留在詳情頁並提供取得方式，不跳出多層錯誤頁。

### 6.3 中斷與錯誤

- 戰鬥內收到斷線：保留目前畫面，顯示重連 overlay；重連成功後以伺服器最新 `stateVersion` 重建盤面。
- PvP 配對／開局流程斷線：回到最後一個已確認步驟，不重新扣除道具或貨幣。
- 單機非戰鬥畫面網路失敗：允許離線繼續，商店與帳號功能標記為暫不可用。
- 投降、購買、升級、取消配對一律二次確認；不可逆的伺服器動作完成後才顯示成功結果。

## 7. Godot 場景與實作順序

建議將可重用元件獨立成場景：`TopBar`、`CurrencyBar`、`CastleCard`、`ClassCard`、`ItemCard`、`ConfirmDialog`、`ReconnectOverlay`。場景建議按下列順序落地：

1. `Boot`、`Onboarding`、`MainHub`、`CampaignMap`、`StageDetail`。
2. `BattlePrep`、`Battle`、`Result`，先完成單機可玩閉環。
3. `TrainingSchool`、`CastleUpgrade`、`Shop`、`Collection`、`Settings`。
4. `PvpLobby`、`Matchmaking`、`MapSelect`、`ClassDraft`、`ItemLoadout`、`DiceRoll`。
5. `ReconnectOverlay`、錯誤處理、返回鍵／手勢、手機安全區與自適應排版。

如此即使 PvP 服務尚未完成，也能先以「主城→戰役→準備→戰鬥→結算→成長」形成可測試的完整產品流程。

## 8. 尚待補的視覺設計

- 主城與戰役地圖的美術風格、色調、字體與 UI 元件庫。
- 各畫面的手機 wireframe（直向／橫向、瀏海安全區、最小觸控尺寸）。
- 連線出擊、共同職業抽選、擲骰、結算與終章的分鏡及可跳過時機。
- 商店貨幣、帳號服務、通知與客服頁是否在第一版上線；可先保留路由與 placeholder。
